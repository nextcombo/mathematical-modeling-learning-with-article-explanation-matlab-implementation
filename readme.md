# Mathematical Modeling Learning [with article explanation] (Matlab implementation)

Parameterized modeling - Using a known model to map the independent variables to the dependent variable with a set of constant unknowns  
Black-box modeling - Using an automatically created model "learn" to map the independent variables to the dependent variable first  
Primitive modeling - Using models derived directly from physical laws without making assumptions such as empirical or fitting parameters.
